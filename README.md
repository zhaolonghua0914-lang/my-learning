## 🛠️ 内容归档与协作规范

1. **自动归类与格式统一**：
   - 所有文档均采用规范 Markdown 格式，具备清晰的层级标题与目录结构。
   - 文件命名采用连字符或语义化英文/拼音命名（如 `iec61131-3-basics.md`）。
2. **安全第一准则**：
   - 严禁提交包含 API Key、个人账号 Token、数据库密码、内网凭证等敏感信息。
   - 本地开发环境及临时产物已通过 `.gitignore` 自动过滤。
3. **持续演进**：
   - 日常碎片记录沉淀在 `Daily-Learning/`，成体系后提炼至对应专业模块。
   - 保持各目录 `README.md` 与根目录索引的同步更新。
