## 🛠️ 核心系统技术要点

### 1. 运动控制与伺服系统 (汇川 Inovance)
- **伺服型号**：汇川 **SV660N 系列** EtherCAT 总线伺服驱动器。
- **通信总线**：EtherCAT 实时工业以太网，支持 CSP / PP / HM 等 CiA 402 标准运动模式。
- **线束匹配**：包含动力线、编码器线及制动电阻线规格匹配清单。

### 2. 电气原理与 IO 分配
- **电气工程图**：EPLAN Electric P8 归档备份工程（`.zw1` 格式），完整定义了主电源回路、24V 配电、安全急停回路、PLC IO 模块接线及伺服驱动回路。
- **IO 映射**：包含最新版《比亚迪IO统计-1115V11.xls》，详细定义了传感器输入、气缸磁性开关、光栅、伺服报警及电磁阀阀岛输出。

### 3. 气动控制
- 分为 **制片段**、**叠台气路** 与 **尾卷段** 3 大气路分区，涵盖气源处理三联件、比例阀、各工位电磁阀组及真空吸盘回路。
