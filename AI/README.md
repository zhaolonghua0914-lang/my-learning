# AI 学习与实验中心

本目录用于记录 AI 相关的工程实践、提示词工程以及系统性的学习笔记。

## 目录结构说明

- `projects/`：AI 相关的项目代码、实验 Demo、模型调用脚本与应用原型。
- `prompts/`：高质量 Prompt 模板、System Prompt 沉淀、角色设定与工作流 Prompt。
- `notes/`：大模型原理、Agent 架构、RAG 技术、知识库构建等学习笔记与技术调研。

## 归档规范

1. 新增项目实践时，在 `projects/` 下建立子文件夹，并附带简要的 `README.md`。
2. 新增 Prompt 时，按用途或场景命名为 `.md` 文件并注明使用方式。
3. 笔记优先以 Markdown 格式沉淀在 `notes/` 目录中。
